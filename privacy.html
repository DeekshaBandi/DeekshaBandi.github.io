Privacy Policy

Markdown & Diagram Viewer: website and browser extension for Chrome and Edge
Effective 17 November 2026

In short: everything is rendered on your device. We do not collect, store, sell or send any personal data, and there are no analytics, tracking, ads or accounts.

What we collect

Nothing. The website and the extension have no server of their own, so nothing you open, type or render is ever sent to us.

What stays on your device

To be useful between visits, the app saves a few things in your browser's local storage. They never leave your device, and you can clear them at any time by clearing the site's data or removing the extension.

  • An unsaved draft of the document you are editing, so it can be recovered.
  • Display preferences, such as theme and scroll sync.

When the app contacts other sites

The app only makes network requests that you trigger:

  • Opening a Markdown file from GitHub. When you open a .md link on raw.githubusercontent.com or gist.githubusercontent.com, the extension downloads that file from GitHub to show it.
  • Images and links inside your document. If a Markdown document contains images hosted elsewhere, your browser loads them from those sites, as it would for any web page. Links you click open in a new tab.

Those sites receive the normal information a browser sends (such as your IP address) and are covered by their own privacy policies. All diagram, math and code rendering uses libraries bundled with the app; no code is downloaded from the internet.

Extension permissions

PermissionWhy it is needed
file:///*Shows local Markdown files you open in the browser. Only works after you turn on “Allow access to file URLs” for the extension.
raw.githubusercontent.com, gist.githubusercontent.comOpens Markdown files from GitHub in the viewer.
downloadsWhen the browser starts downloading a .md file from those locations, the extension cancels the download, removes it from the download list and opens the file in the viewer instead.

The extension does not read your browsing history or the content of other web pages.

Children

The app collects no data from anyone, including children.

Changes

If this policy changes, the updated version will be published on this page with a new effective date.
